# astrbot_plugin_lottery

AstrBot 群聊转盘抽奖插件。

一条命令输入参赛昵称，机器人生成旋转 GIF，减速后停在获奖者扇区并公布结果。

## 功能特性

- 支持命令：`/lucky`（别名：`/抽奖`、`/转盘`）
- 支持分隔符：空格、英文逗号`,`、中文逗号`，`、顿号`、`、分号`;`/`；`
- 自动去重并保持输入顺序
- 公平抽取（`SystemRandom`）
- 生成转盘动画 GIF（默认 34 帧，末帧高亮停留）
- 渲染失败时返回错误 ID（不向用户泄露内部异常细节）
- 自动清理临时 GIF，避免系统临时目录堆积

## 约束说明

- 参与人数上限：20 人
- 实际开奖最少建议：2 人（插件层限制）
- 依赖：Pillow（见 `requirements.txt`）

## 使用方法

### 基本命令

```text
/lucky 小明 小红 小刚
```

### 逗号/顿号分隔

```text
/抽奖 小明,小红、小刚
/转盘 小明，小红；小刚
```

### 返回结果

执行后会先发送一张 GIF，再发送文本结果，格式类似：

```text
🎉 抽奖结果 🎉
🏆 获奖者：小红
参赛者：小明、小红、小刚
```

## 开发与本地调试

### 1) 纯渲染逻辑自检

```bash
py -3.13 _selftest.py
```

该脚本验证：

- 名单解析
- GIF 帧数/尺寸/体积
- 获奖扇区最终停位
- 边界人数与异常输入

### 2) 集成逻辑模拟测试（不依赖真实 AstrBot）

```bash
py -3.13 _simtest.py
```

该脚本会伪造 astrbot API，验证从指令处理到图片/文本回包的完整流程。

### 3) 独立预览转盘 GIF

```bash
py -3.13 wheel.py
```

可选：传入自定义参赛者

```bash
py -3.13 wheel.py 小明 小红 小刚 小丽
```

## 项目结构

- `main.py`：AstrBot 插件入口与命令处理
- `wheel.py`：抽奖与 GIF 渲染核心逻辑（与 AstrBot 解耦）
- `_selftest.py`：渲染与解析自检
- `_simtest.py`：插件流程模拟集成测试
- `metadata.yaml`：插件元数据
- `requirements.txt`：依赖声明

## 常见问题

### 1) 中文字体显示不理想

插件会自动尝试常见中文字体路径；若未找到会回退到 Pillow 默认字体。可在部署环境安装中文字体以获得更好显示效果。

### 2) 渲染失败怎么办

用户侧会收到错误 ID；管理员可在日志中按该 ID 检索详细异常栈。

### 3) 为什么限制最多 20 人

人数过多会导致扇区过窄、昵称严重重叠，影响可读性与出图质量。
